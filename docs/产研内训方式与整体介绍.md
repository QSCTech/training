# 产研内训方式与整体介绍

| 方向 | 学习路线 | 最终实践 |
| --- | --- | --- |
| 产品运营 | [产品运营方向](product-operations/产品运营方向.md)：了解产品 → 调研与分析 → 方案设计 → 项目验证 → 推广与迭代 | 产品方案、原型、测试与反馈闭环 |
| 技术研发 | [技术研发方向](technical-development/技术研发方向.md)：开发基础 → 前端或后端 → 协作开发 → 项目交付 | 可运行的 Web 项目与技术复盘 |

两个方向可交叉学习。

## 使用方式

每篇学习节点都包含正文和练习。可以在本地文档中完成练习并记录笔记；各方向首页标出建议顺序和选修主题，如果已有基础，可以直接进入对应阶段。如果在本地obsidian查看，可以通过修改`status`来标记已学习部分。

## 本地点亮知识图谱

每篇文档的 YAML frontmatter 都带有 `status: unread`。完成学习后，将当前文档改为 `status: done`；这个状态只保存在本地，不需要提交或推送。

打开 Obsidian 的关系图谱即可看到颜色反馈：`status: done` 的节点显示荧光绿，`status: unread` 的节点显示暗灰色。图谱分组已经写入 `docs/.obsidian/graph.json`，不需要安装插件。
