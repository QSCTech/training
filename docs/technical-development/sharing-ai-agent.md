# 技术分享：AI Agent 与编程助手

AI Agent 可以看作“模型 + 工具 + 循环”。模型负责理解和生成，工具读取文件、执行命令或调用 API，循环根据工具结果继续计划和校验。

## 一个可靠的工作循环

1. 明确目标、约束和验收条件。
2. 先读取项目结构、规范和相关代码。
3. 把大任务拆成可检查的小步骤。
4. 每次修改后运行针对性的测试或静态检查。
5. 审查差异，确认没有凭空添加依赖、泄露密钥或改动无关文件。

AI 生成的代码必须由提交者理解和测试。涉及服务器、数据删除、权限、支付或外部发布的操作要先确认范围，并保留可追溯记录。

## Prompt 模板

```md
目标：
项目背景：
允许修改的文件：
必须保持的行为：
验收标准：
请先给出计划，再逐步修改并说明验证结果。
```

## 练习

- [ ] 用上述模板让助手为一个小功能提出计划。
- [ ] 对生成的代码逐行说明输入、输出和失败路径。
- [ ] 记录一次 AI 建议错误的原因和修正方式。
