# UML 建模

UML 是统一建模语言，用图形描述系统结构、角色和行为。它帮助产品、设计和技术在实现前建立共同语言。

## 常用图

- **类图**：类、属性、方法及其关系。
- **用例图**：系统外部角色与系统提供的功能。
- **活动图**：业务流程、分支和并发。
- **状态机图**：一个对象在生命周期中的状态和转换条件。
- **时序图**：多个对象按时间顺序交换消息。

## 常见关系

关联表示对象之间长期存在的联系；继承表示“是一个”；实现表示类遵守接口；依赖表示临时使用；聚合和组合表示整体与部分。多重性可写成 `0..1`、`1..*` 等。

## 建模步骤

1. 从需求文字中找出角色、实体、动作和状态。
2. 为实体补充必要属性和行为。
3. 画出关系和多重性。
4. 用一个具体场景走通流程，删除不必要的细节。
5. 让图和 PRD、API、数据库模型保持一致。

例如待办系统可先画“用户创建待办”的用例图，再用时序图描述浏览器、API、服务层和数据库的交互。
